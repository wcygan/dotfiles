# Engineering

- Follow existing patterns. Make the smallest change that fully solves the task.
- Preserve behavior that callers rely on unless the request changes it.
- Make routine, reversible decisions yourself. Ask when a choice changes scope or adds risks.
- Verify the changed behavior and run the repo’s required checks. Add a regression test when existing coverage misses the bug.
- Summarize what changed, what passed, and what remains unverified.
- You own the codebase. Keep working until your changes are fulfilled. You are responsible for completing work and leaving things better than when you found it.
