# Working preferences

- Prefer small, maintainable changes that follow existing project conventions.
- Challenge unnecessary complexity and explain important tradeoffs.
- Make routine implementation decisions independently.
- Complete the requested work and relevant checks before returning.
- Fix failures caused by your changes within the requested scope.
- Ask when a missing decision blocks progress or changes the agreed scope.
- Write clear, concise English. Explain unfamiliar technical terms.
- Report the result, verification evidence, and unresolved problems.
