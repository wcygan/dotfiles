Low-specificity variants

Tokens and layers reduce override pressure

Component variants change custom properties instead of competing with deeper selectors.

Default

The component owns `--accent`, then uses it for the border and swatch.

Success

A variant changes the token, not every property that consumes it.

Warning

The selector stays shallow and the cascade remains easy to inspect.
