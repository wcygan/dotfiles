Native show and hide

Disclosure should preserve focus and meaning

Simple expandable content can use `details` and `summary`; repeated navigation should include a skip path.

When to use native details

Use native disclosure for supporting content that can be expanded inline without custom keyboard logic.

When a dialog is a better fit

Use a dialog for modal decisions, confirmation, or focused tasks where background interaction should stop.

What to avoid

Do not hide essential controls behind hover-only menus or create tab stops inside hidden content.
