Rendered evidence first

Debug layout by inspecting boxes and cascade

A repeatable checklist turns CSS debugging into a visible sequence instead of a guessing session.

  1. Check the box model

    Inspect width, padding, border, margin, intrinsic size, and `box-sizing` before changing layout rules.

  2. Toggle matched rules

    Disable one declaration at a time until the visual behavior changes for the reason you expect.

  3. Use layout overlays

    Grid and Flexbox overlays expose tracks, alignment, gaps, and wrapping more clearly than source code alone.

  4. Measure overflow

    Compare scroll width with viewport width and test long labels when a page leaks horizontally.
