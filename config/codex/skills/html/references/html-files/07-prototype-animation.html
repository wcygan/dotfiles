Prototype

Animation sandbox

A motion tuning artifact for evaluating timing, easing, sequencing, and celebratory feedback.

  • Primary intent: motion prototype
  • Interaction: replay/tuning
  • Output: CSS or timing values

Use when

The key uncertainty is how a micro-interaction should feel, not where it should go.

Input signals

  • "Animation", "easing", "duration", "micro-interaction", "play animation".
  • One component or state transition to isolate.
  • Need for sliders, replay, or copyable parameters.

Borrow

  • Isolated interactive demo.
  • Easing and timing controls near the animation.
  • Keyframe timeline and copyable CSS/parameters.

Avoid

  • Multi-screen workflows or drag/drop evaluation.
  • Decorative motion that does not clarify state.
  • Ignoring reduced-motion needs.

Pair with

Use `06-component-variants.html` for static states or `08-prototype-interaction.html` when workflow feel matters more than timing.

Validation

  • Replay and reset work.
  • Exported CSS/parameters match the current controls.
  • Motion remains usable under reduced-motion assumptions.
