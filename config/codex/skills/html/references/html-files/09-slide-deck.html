Slide deck

A one-file presentation artifact for short demos, status readouts, or decision meetings.

  • Primary intent: present
  • Interaction: keyboard navigation
  • Output: slide narrative

Use when

The user wants a shareable presentation without using slide software or a build step.

Input signals

  • "Deck", "slides", "presentation", "demo", "talk track".
  • Small set of points to present live.
  • Need for metrics, shipped work, and a decision ask.

Borrow

  • One main idea per full-screen section.
  • Keyboard navigation and progress indicator.
  • Concise slide copy designed to be spoken over.

Avoid

  • Long prose reports.
  • Implementation handoffs with lots of code.
  • Hidden controls that make the deck hard to present.

Pair with

Use `11-status-report.html` for source status content or `16-implementation-plan.html` when slides summarize a plan.

Validation

  • Arrow keys or visible controls navigate slides.
  • Slide count/progress is correct.
  • The deck remains readable if printed or viewed statically.
