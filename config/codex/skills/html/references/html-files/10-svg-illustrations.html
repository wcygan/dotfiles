Illustrations and diagrams

SVG illustration sheet

A collection artifact for several related SVG figures that need a consistent visual language and export path.

  • Primary intent: illustrate
  • Interaction: download/copy
  • Output: reusable SVGs

Use when

The user needs multiple diagrams, blog figures, or documentation illustrations in one reviewable sheet.

Input signals

  • "SVG", "illustrations", "figure sheet", "diagram set", "download SVG".
  • Need for a shared style across several graphics.
  • Figures will be copied into docs or posts.

Borrow

  • Inline SVG figures with consistent stroke, palette, and labels.
  • Caption naming the intended use of each figure.
  • Download/copy controls per SVG.

Avoid

  • Using it for one complex operational flow with step details.
  • Relying on external image assets.
  • Export buttons that do not produce standalone SVG.

Pair with

Use `13-flowchart-diagram.html` for clickable workflow details or `15-research-concept-explainer.html` for interactive teaching visuals.

Validation

  • SVG labels fit at target size.
  • Exported SVG opens standalone.
  • All figures share visual grammar.
