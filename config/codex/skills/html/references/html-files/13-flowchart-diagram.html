Annotated flowchart

A workflow diagram artifact for showing process steps, decisions, success paths, and failure paths with detail on demand.

  • Primary intent: diagram workflow
  • Interaction: clickable nodes
  • Output: operational map

Use when

The user needs to understand or communicate a pipeline, deployment flow, approval flow, or other stepwise process.

Input signals

  • "Flowchart", "pipeline", "workflow", "what happens when", "failure path".
  • Ordered steps, decisions, timings, owners, commands, or systems.
  • Need to click steps for details.

Borrow

  • SVG flowchart with clear shape categories.
  • Legend and detail panel.
  • Success, failure, and rollback paths.

Avoid

  • Multiple unrelated illustrations in one chart.
  • Dense text inside nodes.
  • Unclickable nodes when the page promises details.

Pair with

Use `10-svg-illustrations.html` for reusable figure sheets or `04-code-understanding.html` when the flow is a call path through source files.

Validation

  • Every node has accurate detail.
  • Failure paths are visually distinct.
  • The flow is understandable on a narrow viewport.
