Feature explainer

A source-backed teaching artifact for explaining how a repo feature behaves, where it is configured, and what can go wrong.

  • Primary intent: explain feature
  • Interaction: details and tabs
  • Output: teachable summary

Use when

The user asks how a specific feature works and expects a concise explanation grounded in source files.

Input signals

  • "Explain rate limiting", "how does this feature work", "gotchas", "FAQ".
  • Middleware, config, route handlers, clients, tests.
  • Need to show files read and source snippets.

Borrow

  • Files-read chips and TL;DR.
  • Expandable request/path steps.
  • Tabbed config/code examples, gotchas, FAQ.

Avoid

  • Explaining general theory without local source.
  • Architecture diagrams that skip practical configuration.
  • Claims that cannot be tied to source files.

Pair with

Use `04-code-understanding.html` for deeper callstack traversal or `15-research-concept-explainer.html` for general concepts behind the feature.

Validation

  • Source file chips match files actually inspected.
  • Tabbed examples switch correctly.
  • Gotchas are concrete and source-backed.
