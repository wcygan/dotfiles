Concept explainer

An interactive learning artifact for making an abstract technical concept tangible through controls and visualization.

  • Primary intent: teach concept
  • Interaction: live visualization
  • Output: intuition

Use when

The user wants to understand a concept, algorithm, or tradeoff that benefits from a manipulable model.

Input signals

  • "Teach me", "interactive explainer", "show how parameters affect", "concept".
  • Algorithmic or systems idea with adjustable variables.
  • Need for glossary and baseline comparison.

Borrow

  • Plain-language concept framing.
  • Interactive visualization with sliders/buttons.
  • Comparison table and hover-linked glossary.

Avoid

  • Repo-specific feature explanation where source files matter more.
  • Overcomplicated controls that obscure the idea.
  • Visuals that are blank or meaningless without JavaScript unless clearly labeled.

Pair with

Use `14-research-feature-explainer.html` for source-backed feature behavior or `10-svg-illustrations.html` for static figures.

Validation

  • Controls visibly change the model.
  • Comparison table is accurate.
  • The page still communicates the core idea without interaction.
