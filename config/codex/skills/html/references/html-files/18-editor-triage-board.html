Custom editor

Ticket triage board

A one-off editor for sorting, prioritizing, and exporting a set of tickets or work items.

  • Primary intent: edit priorities
  • Interaction: drag and export
  • Output: ordered Markdown

Use when

The user needs to manipulate a list into buckets such as Now, Next, Later, and Cut.

Input signals

  • "Triage", "prioritize", "sort tickets", "drag cards", "bucket".
  • Linear/Jira/GitHub issues, feedback items, tests, candidates.
  • Need to export the final ordering back into a prompt or doc.

Borrow

  • Columns with counts and draggable cards.
  • Tag filters, reset, and copy-as-Markdown.
  • Pre-sorted best guess with rationale when useful.

Avoid

  • Using it for config constraints or prompt editing.
  • Drag-only controls when keyboard accessibility matters.
  • Exports that omit enough context to be useful later.

Pair with

Use `16-implementation-plan.html` after priorities are chosen, or `11-status-report.html` to summarize the triage outcome.

Validation

  • Drag/drop and reset work.
  • Counts update correctly.
  • Markdown export reflects current ordering.
