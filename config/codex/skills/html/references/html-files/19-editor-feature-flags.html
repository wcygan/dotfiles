Custom editor

Feature flag editor

A constrained config editor for toggles, dependencies, warnings, and diff export.

  • Primary intent: edit config
  • Interaction: form and export
  • Output: JSON or diff

Use when

The user needs to edit structured configuration safely with validation and copyable output.

Input signals

  • "Feature flags", "config editor", "dependencies", "copy diff", "JSON".
  • YAML/JSON config with booleans, percentages, prerequisites, or grouped areas.
  • Need to warn about invalid combinations.

Borrow

  • Grouped toggles and dependency warnings.
  • Changed-key summary and dirty-state controls.
  • Copy diff, copy full JSON, and reset.

Avoid

  • Read-only explainers where editing is not needed.
  • Allowing invalid states without warning.
  • Exporting the whole config when the user asked for only changes.

Pair with

Use `14-research-feature-explainer.html` for explaining how config is consumed, or `18-editor-triage-board.html` for non-config bucketing.

Validation

  • Warnings appear for broken dependencies.
  • Reset restores original state.
  • Diff export contains only changed keys.
