Prompt tuner

A live template editor for tuning prompts, variables, sample inputs, and copyable output.

  • Primary intent: tune prompt
  • Interaction: live preview
  • Output: prompt text

Use when

The user needs to adjust a prompt, template, or copy while seeing how real sample inputs render.

Input signals

  • "Prompt tuner", "template variables", "live preview", "copy prompt".
  • System prompt, email copy, support response template, variable slots.
  • Need for counters, previews, and reset.

Borrow

  • Editable template and highlighted slots.
  • Available slot list and character/token estimates.
  • Multiple sample previews, reset, and copy prompt.

Avoid

  • Static prompt specs where no interactive tuning is needed.
  • Handling paste poorly in contenteditable areas.
  • Preview data that does not cover the prompt's real edge cases.

Pair with

Use `15-research-concept-explainer.html` for teaching concepts or `19-editor-feature-flags.html` for structured config constraints.

Validation

  • Typing updates previews.
  • Slots are highlighted and listed accurately.
  • Copy/export returns the current prompt.
