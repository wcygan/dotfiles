## Routing Heuristics

- For "what is TiDB", read overview, features, and architecture.
- For components, read architecture first, then TiKV, TiFlash, PD scheduling, or TSO.
- For local demos, start with quick start and TiUP playground.
- For production deployment, start with requirements, checklist, topology, TiUP deployment, and post-install checks.
- For MySQL compatibility, start with MySQL compatibility and limitations, then hand off to `tidb-sql` for SQL generation.
- For query plans or slow queries, start with EXPLAIN and SQL tuning pages, then hand off to `tidb-query-tuning`.
- For application code, start with Developer docs and then use language-specific pages.
- For operations incidents, start with troubleshooting map, relevant scenario page, dashboard, statement summary, Top SQL, and SQL Plan Replayer.
- For vector or full-text search, start with TiDB for AI docs, then hand off to `tidb-sql` if SQL syntax must be produced.
